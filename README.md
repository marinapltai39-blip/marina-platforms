# Marina Platforms — Technical Site | منصات مارينا

Public catalog site for **Marina Platforms**: catalogues, flyers, and technical
offers (elevators, boom & scissor lifts, parking systems, scaffolding, ladders,
dock levelers). Browse and download all technical files. Arabic / English.

الموقع العام لمنصات مارينا: كتالوجات وفلايرات وعروض فنية — تصفّح وتحميل، عربي/إنجليزي.

## Live site (GitHub Pages)
After enabling GitHub Pages (Settings → Pages → Branch: `main` → `/root`),
the site is served at:  `https://<username>.github.io/<repo>/`

## What is here
- `index.html` — the site (static, no server needed)
- `manifest.js` — generated site data (the catalog tree)
- `assets/` — logo
- `files/` — the actual PDFs / Word docs / images (the content)

## Note
This is the **public static site only**. The admin panel (upload / edit /
delete) needs a Node.js server and is not part of GitHub Pages — it runs
separately (locally or on Node hosting).

لوحة التحكم (الرفع والتعديل) مش جزء من GitHub Pages — بتشتغل على سيرفر Node منفصل.
